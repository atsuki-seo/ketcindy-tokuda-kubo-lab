### B1. 内分点と外分点（単元1 2点間の距離と内分点）

- ページ: `math2/section-point.html`、両用の cdy: [src/math2/section-point.cdy](../src/math2/section-point.cdy)
- プリントとの対応: 【平面上の内分点・外分点】
- 元にした cdy: su2(2s)2501c/su2(2m)2401w4の図.cdy（線分 AB 上の点 P と、各点から軸に下ろした点）
- Web 版では P を m:n のスライダーで決め、外分も切り替えて見られるようにした。
- 元の cdy: su2(2s)2501c/su2(2m)2401w4の図.cdy
- 図の切り替え: 内分／外分
- この教材でわかること: 線分 AB を m:n に内分・外分する点の座標が、x 座標・y 座標それぞれで数直線上の内分・外分の式になることを確かめる。
- 動かしてみよう:
  1. 点 A・B を動かし、AB を m:n に分ける点 P の位置と、x 軸・y 軸に下ろした点の位置を見る。
  2. スライダーで m・n を変え、P の座標が ((na+mb)/(m+n), …) の式どおりに変わることを確かめる。
  3. 外分に切り替え、m > n と m < n で P が A の側・B の側のどちらに出るかを比べる。
- 確かめよう: A(−2, 1)、B(4, 4) のとき、線分 AB を 2:1 に内分する点と外分する点を求めよ。
  - 答え: 内分点 ((1·(−2)+2·4)/3, (1·1+2·4)/3) = (2, 3)。外分点 ((−1·(−2)+2·4)/(2−1), (−1·1+2·4)/(2−1)) = (10, 7)

### B2. 直線の傾きと切片（単元2 直線の式）

- ページ: `math2/line-slope-intercept.html`、スクリプト: [src/math2/line-slope-intercept.cs](../src/math2/line-slope-intercept.cs)
- プリントとの対応: 【直線の傾きと切片】
- 新規作成（対応する cdy なし）
- この教材でわかること: 直線 y = ax + b の a（傾き）を変えると直線の傾き方が、b（y 切片）を変えると y 軸と交わる位置が変わることを確かめる。
- 動かしてみよう:
  1. スライダーで a を変え、x が 1 増えると y が a だけ増える（a が負なら減る）ことを、直角三角形の縦の長さで確かめる。
  2. スライダーで b を変え、直線が y 軸と交わる点 (0, b) が動くことを確かめる。
  3. a = 0 にすると、x 軸に平行な直線 y = b になることを確かめる。
- 確かめよう: 2点 (1, 3)、(3, 7) を通る直線の傾きと y 切片を求めよ。
  - 答え: 傾き a = (7 − 3)/(3 − 1) = 2。y = 2x + b に (1, 3) を代入して b = 1。y = 2x + 1（傾き 2、y 切片 1）

### B3. 直線の平行と垂直（単元3 直線の平行と垂直）

- ページ: `math2/line-parallel-perpendicular.html`、スクリプト: [src/math2/line-parallel-perpendicular.cs](../src/math2/line-parallel-perpendicular.cs)
- プリントとの対応: 【直線の平行と垂直】
- 新規作成（対応する cdy なし）
- この教材でわかること: 2直線 ℓ₁: y = m₁x + n₁ と ℓ₂: y = m₂x + n₂ が平行なら m₁ = m₂、垂直なら m₁·m₂ = −1 になることを確かめる。
- 動かしてみよう:
  1. 点 A・B を動かして直線 ℓ₁ を決める。点 C を動かし、スライダーで ℓ₂ の傾き m₂ を変える。
  2. ℓ₂ を ℓ₁ と平行にしたときの m₁ と m₂ を比べる。
  3. ℓ₂ を ℓ₁ と垂直にしたときの m₁·m₂ の値を読む。
- 確かめよう: 点 (2, 1) を通り、直線 y = 3x − 1 に平行な直線と垂直な直線を求めよ。
  - 答え: 平行な直線は傾き 3 なので y − 1 = 3(x − 2) より y = 3x − 5。垂直な直線は傾き −1/3 なので y − 1 = −(1/3)(x − 2) より x + 3y − 5 = 0

### B4. 直線に関して対称な点（単元3 直線の平行と垂直）

- ページ: `math2/line-symmetric-point.html`、両用の cdy: [src/math2/line-symmetric-point.cdy](../src/math2/line-symmetric-point.cdy)
- プリントとの対応: 【例題3】（直線に関して対称な点）
- 元にした cdy: su2(2s)2503c/su2(2s)2304wの図.cdy（例題3 の図。ℓ: x − y − 1 = 0、P(5, 1)、Q(2, 4)）
- Web 版では P と ℓ を動かせるようにした。
- 元の cdy: su2(2s)2503c/su2(2s)2304wの図.cdy
- この教材でわかること: 直線 ℓ に関して点 P と対称な点 Q は、「PQ ⊥ ℓ」と「PQ の中点が ℓ の上にある」の 2 つの条件で決まることを確かめる。
- 動かしてみよう:
  1. 点 P を動かし、対称な点 Q がどこに移るかを見る。
  2. PQ の傾きと ℓ の傾きの積がいつも −1 になること、PQ の中点 R がいつも ℓ の上にあることを確かめる。
  3. 点 L₁・L₂ を動かして直線 ℓ を変え、同じことが成り立つかを確かめる。
- 確かめよう: 直線 ℓ: y = x + 1 に関して、点 P(3, 0) と対称な点 Q を求めよ。
  - 答え: Q(a, b) とする。PQ ⊥ ℓ より (b − 0)/(a − 3) = −1 で a + b = 3。中点 ((a + 3)/2, b/2) が ℓ 上にあるので b/2 = (a + 3)/2 + 1 で a − b = −5。これを解いて Q(−1, 4)

### B5. 円の方程式（単元5 円の式）

- ページ: `math2/circle-equation.html`、スクリプト: [src/math2/circle-equation.cs](../src/math2/circle-equation.cs)
- プリントとの対応: 【円の方程式（標準形）】【円の方程式（一般形）】
- 新規作成（対応する cdy なし）
- この教材でわかること: 中心 (a, b)、半径 r の円の上の点 P は、中心からの距離がいつも r なので (x − a)² + (y − b)² = r² を満たす。展開すると一般形 x² + y² + lx + my + n = 0 になる。
- 動かしてみよう:
  1. 円の上の点 P を動かし、CP がいつも半径 r に等しいことを確かめる。
  2. 中心 C を動かし、標準形の a・b と、一般形の l・m（x・y の係数）がどう変わるかを見る。
  3. スライダーで半径 r を変え、一般形の定数項 n = a² + b² − r² が変わることを確かめる。
- 確かめよう: 円 x² + y² − 4x + 6y − 3 = 0 の中心と半径を求めよ。
  - 答え: 平方完成すると (x − 2)² + (y + 3)² = 16。中心 (2, −3)、半径 4

### B6. 円を伸ばして楕円へ（単元7 楕円の式）

- ページ: `math2/circle-to-ellipse.html`、両用の cdy: [src/math2/circle-to-ellipse.cdy](../src/math2/circle-to-ellipse.cdy)
- プリントとの対応: 【楕円】
- 元にした cdy: su2(2s)2507c/円の変形.cdy（A を x 軸、B を y 軸の上で動かして楕円を描く）

- 元の cdy: su2(2s)2507c/円の変形.cdy
- この教材でわかること: 円 x² + y² = 1 を x 軸方向に a 倍、y 軸方向に b 倍すると、楕円 x²/a² + y²/b² = 1 になることを確かめる。
- 動かしてみよう:

  3. a = b にすると円に戻ることを確かめる。

  - 答え: x 軸方向に 5 倍、y 軸方向に 3 倍したもの。x 軸との交点 (±5, 0)、y 軸との交点 (0, ±3)

### B7. 楕円と焦点（単元7 楕円の式）

- ページ: `math2/ellipse-focus.html`、両用の cdy: [src/math2/ellipse-focus.cdy](../src/math2/ellipse-focus.cdy)
- プリントとの対応: 【楕円と焦点】【楕円の焦点のまとめ】
- 元にした cdy: su2(2s)2507c/su2(2s)2211w楕円1.cdy（Ch=[3]: 焦点 F₁, F₂ と楕円上の点 P）
- Web 版では P を楕円の上で動かせるようにし、a・b をスライダーで変えられるようにした。
- 元の cdy: su2(2s)2507c/su2(2s)2211w楕円1.cdy
- この教材でわかること: 楕円の上のどこに P があっても、2つの焦点からの距離の和 PF₁ + PF₂ は一定（横長なら 2a、縦長なら 2b）になることを確かめる。
- 動かしてみよう:
  1. 楕円の上の点 P を一周させ、PF₁・PF₂ が変わっても和は変わらないことを確かめる。

  3. a < b にして縦長の楕円にすると、焦点が y 軸の上 (0, ±c) に移ることを確かめる。
- 確かめよう: 楕円 x²/9 + y²/6 = 1 の2つの焦点を求めよ。
  - 答え: a² = 9 > b² = 6 なので横長。c² = 9 − 6 = 3 より c = √3。焦点 (√3, 0)、(−√3, 0)

### B8. 双曲線と漸近線（単元8 双曲線の式）

- ページ: `math2/hyperbola-asymptote.html`、両用の cdy: [src/math2/hyperbola-asymptote.cdy](../src/math2/hyperbola-asymptote.cdy)
- プリントとの対応: 【双曲線の標準形】【双曲線の焦点のまとめ】
- 元にした cdy: su2(2s)2508c/su2(2s)2212wグラフ(画面).cdy の Ch=[4]（A₁, B₁ を動かして双曲線を描く）
- その cdy は HTML 版で白紙になる。Hyperbolaplot に "Asy=do"（漸近線を描くオプション）を付けると例外が出るため。
- Web 版では双曲線を Paramplot で、漸近線を Lineplot で別に描く。
- 元の cdy: su2(2s)2508c/su2(2s)2212wグラフ(画面).cdy
- 図の切り替え: 左右に開く（= 1）／上下に開く（= −1）
- この教材でわかること: 双曲線 x²/a² − y²/b² = ±1 は、点線の長方形の対角線を延ばした直線 y = ±(b/a)x（漸近線）に近づいていく。焦点は長方形の頂点を通る円と軸の交点 (±c, 0) または (0, ±c) で、c² = a² + b² になる。
- 動かしてみよう:
  1. 点 A₁ を x 軸の上で、点 B₁ を y 軸の上で動かし、長方形と漸近線、双曲線の形がどう変わるかを見る。
  2. 双曲線の上の点 P を動かし、|PF₁ − PF₂| がいつも一定（左右なら 2a、上下なら 2b）になることを確かめる。
  3. 焦点が、長方形の頂点を通る円（半径 c = √(a² + b²)）と軸の交点にあることを確かめる。
- 確かめよう: 双曲線 x²/16 − y²/9 = 1 の焦点と漸近線を求めよ。
  - 答え: c² = 16 + 9 = 25 より c = 5。焦点 (5, 0)、(−5, 0)。漸近線 y = (3/4)x、y = −(3/4)x

### B10. 2次曲線の接線（単元10 2次曲線の接線）

- ページ: `math2/conic-tangent.html`、両用の cdy: [src/math2/conic-tangent.cdy](../src/math2/conic-tangent.cdy)
- プリントとの対応: 【2次曲線の接線】
- 元にした cdy: su2(2s)2510c/su2(2s)22510c動かす.cdy（Ch=[1]〜[3] の 3 図をボタンで切り替える）
- 元の cdy: su2(2s)2510c/su2(2s)22510c動かす.cdy
- 図の切り替え: 楕円／放物線／双曲線
- この教材でわかること: 直線を平行に動かし、2次曲線と接する（共有点が1個になる）ときに、連立した2次方程式の判別式が 0 になることを確かめる。
- 動かしてみよう:
  1. スライダーの C を動かし、直線と曲線の共有点が 2個 → 1個 → 0個 と変わるところを探す。
  2. 接するとき（共有点が1個のとき）の C の値と、判別式 D/4 の値を読む。D/4 の符号と共有点の個数の関係を確かめる。
  3. ボタンで放物線・双曲線に切り替え、同じように接する C を探す。
- 確かめよう: 楕円 x²/9 + y² = 1 の接線で、傾きが 1 のものを求めよ。
  - 答え: y = x + k を代入すると 10x² + 18kx + 9k² − 9 = 0。D/4 = 81k² − 10(9k² − 9) = −9k² + 90 = 0 より k = ±√10。答え: y = x ± √10

### B11. 不等式の表す領域（単元11 不等式と領域）

- ページ: `math2/inequality-region.html`、両用の cdy: [src/math2/inequality-region.cdy](../src/math2/inequality-region.cdy)
- プリントとの対応: 【例題1】【問2】（不等式の表す領域）
- 元にした cdy: su2(2s)2511c/a.cdy（Ch=[1]〜[4]）、su2(2s)2511c/d.cdy（Ch=[3]: y = x + 1 と 2x + y = 2）
- Web 版では斜線の代わりに領域に色を付け、点 T を代入して確かめられるようにした。
- 元の cdy: su2(2s)2511c/a.cdy
- 図の切り替え: y > 3／x < 3／x + 2y − 2 < 0／x² + y² < 4／連立不等式
- この教材でわかること: 不等式を満たす点 (x, y) の集まりが、境界の直線や円で分けられた片側（領域）になることを、点を動かして式に代入しながら確かめる。

  2. 境界の線の上に T を置き、境界を含むか含まないか（等号が付くか）で ○ と × が変わることを確かめる。
  3. 連立不等式では、2つの不等式の両方が成り立つところが領域になることを確かめる。
- 確かめよう: 不等式 y < 2x − 1 の表す領域を答えよ。
  - 答え: 直線 y = 2x − 1 の下側。ただし、境界の直線は含まない

### C1. 2点間の距離

- 解き方:
  1. AB = √((x₂ − x₁)² + (y₂ − y₁)²)
  2. = √((−2 − (−1))² + (−4 − (−4))²)
  3. = √(1 + 0) = √1
  4. = 1
