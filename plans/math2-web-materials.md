# 数学2の Web 教材の計画

## 目的

数学2（2年 S2）の授業で使っている tex（授業プリント・過去問）と cdy を元に、公開ページへ「数学2」の科目を加える。
授業の単元に合わせて、点やスライダーを動かして確かめられる教材 14 本と、練習問題のページを公開する。

## 元にする授業資料

- 担当教員の授業資料フォルダ `2025-2s-数学2`（このリポジトリの外）にある。
- ファイル名の `25NN` の NN が単元番号（2501〜2515）。末尾の文字は `c` が授業プリント、`p` がプリント、`w` が試験対策・過去問、`x` が長期休みの宿題。
- tex は 143 個、cdy は 53 個。解答例は `\ckai` / `\ckkai` で出し分けている。前期・後期の中間・期末の過去問が 2022〜2024 年度分ある。
- cdy は zip で、描画スクリプトは `private/de.cinderella/scripts/Draw/0/figures.cs`、点や表示範囲（SW/NE）は `private/de.cinderella/construction.cdy`（平文）に入っている。
- 1 つの cdy の中で `Ch=[...]` を切り替えて、印刷用の図を何枚も書き出す作りになっている。名前に `(画面)` や `提示用` が付いたものは、授業中に画面で動かして見せる前提で作られている。

## ページの階層

```
index.html                    教材一覧（科目の一覧）
└ math2/index.html            数学2（章ごとに見出しを付け、単元の順に並べる）
   ├ math2/<教材>.html         教材ページ
   └ math2/drill-<型>.html     練習問題
```

- URL は今の「教材一覧 → 科目 → 教材」の 2 段のままにし、章のディレクトリは作らない。
  [tools/site.mjs](../tools/site.mjs) は、各ページから出力先直下への相対パスを `""` か `"../"` の 2 通りだけ前提にしているため。
- 章は一覧ページの見出しで表す。点と直線（単元1〜3）／円と2次曲線（単元5〜10）／不等式と領域（単元11）／ベクトル（単元12〜14）／練習問題。章の名前は仮。
- 一覧の各行には「単元7」のような単元タグを付け、授業プリントと同じ番号で探せるようにする。
- ファイル名は英字にする（例: `ellipse-focus.html`）。

## 教材ページの構成

上から順に並べる。

1. パンくずと見出し（今のツールのまま）
2. 単元タグとプリントとの対応（例: 「単元7 楕円の式」「プリント【楕円と焦点】」）
3. この教材でわかること（1〜2 行）
4. キャンバス。点やスライダーを動かすと、値（PF₁・PF₂ とその和など）がその場で変わる。cdy の `Ch` による図の切り替えは、ボタンかスライダーにする。
5. 動かしてみよう（操作の指示を 2〜3 個）
6. 確かめよう（プリントや過去問と同じ型の問題を 1 問。答えは `<details>` で開く）
7. 前後の教材へのリンク（単元の順）

## 進め方

### 0. 担当教員と決めること

- 「（仮）」の教材 3 本のタイトルと、章の名前
- cdy の扱い。担当教員の cdy を Web 版と両用できるように書き換えるか、このリポジトリに Web 用のコピーを持つか（コピーを持つと二重管理になる）
- 公開してよい問題。リポジトリと GitHub Pages は公開されている。tex の問題には教科書や問題集からの引用があるので、「確かめよう」や練習問題では数値を変えるか、可否を確認する。

### 1. 第1弾: 「2次曲線の接線」を公開する

- [tools/site.mjs](../tools/site.mjs) の `CATEGORIES` に `{ slug: "math2", name: "数学2" }` を足す。
- 試作で動作を確かめた接線の教材を `src/` に移す。楕円・放物線・双曲線の 3 図は、ボタンかスライダーで切り替える。
- 接する C の値（楕円 x²/16+y²/4=1 と傾き 1 の直線なら ±2√5）を `--assert` で確かめ、CI にも組み込む。
- 判断が必要なところ: 図の切り替え方と、画面に何の値を出すか。

### 2. ツールの拡張 A: ページの構成を整える

- スクリプトのコメントからメタ情報を読む（`// @title` / `// @category` と同じ書き方）。

  ```
  // @unit 7 楕円の式
  // @print 【楕円と焦点】
  // @lead 楕円上のどこに P があっても PF₁+PF₂ は一定になる
  // @step P を楕円上で一周させ、和を観察する
  // @check x^2/9+y^2/6=1 の2焦点は？ | (±√3, 0)
  ```

- [tools/make-index.mjs](../tools/make-index.mjs) で、一覧を章見出し付き・単元順に並べ、前後の教材へのリンクを作る。
- 説明文が長くなってコメントでは書きにくくなったら、教材ごとに Markdown のファイルを別に置く方式に切り替える。
- 判断が必要なところ: メタ情報に書く文章（教材の説明として書く文章なので、担当教員に確認してもらう）。

### 3. ツールの拡張 B: `Putoncurve` に対応する

- 曲線や線分の上を動く点を、HTML 版でも用意できるようにする（[tools/ketjs-build.mjs](../tools/ketjs-build.mjs)）。
- これで「内分点と外分点」「楕円と焦点」「放物線の焦点と準線」「線形結合」が動く見込み。
- 実現できるかはまだ分からない。KeTCindy の内部を調べて試す作業になる。

### 4. 残りの教材を移す・作る

- 教材ごとに「教材仕様」を下書きし、担当教員に確認してもらってから実装する。
  仕様に書くこと: 何を動かすか／画面に何を表示するか／学生に何に気づいてほしいか／動かしてみよう／確かめようの問題と正解として扱う範囲。
- 新規作成の 3 本（直線の傾きと切片、直線の平行と垂直、円の方程式）は、何を動かすと何に気づけるかを一から設計する。
- 改修の 2 本（直線に関して対称な点、楕円と焦点）は、どの点を動かせるようにするかを決める。
- 双曲線と漸近線は、白紙になる原因を調べてから作業量を見積もる。
- 表示範囲がずれる場合は、`.cdy` を直接読み込み、`construction.cdy` の SW/NE と点の位置を使えるようにする。
- KaTeX で読めない TeX マクロ（`\wx`、`\bekutoru` など）は、`//only ketjs` で HTML 版用の書き方を別に用意する。
- assert の期待値は計算で出せるが、教材として正しいかは担当教員に確認してもらう。

### 5. 練習問題

段階 2〜4 の教材ができてから取りかかる。

各段階で共通して、教材ごとに正しい値を `--assert` で確かめ、スマートフォン（390×844）とタブレット（820×1180）の幅で表示を確かめる。

## 練習問題の方針（決定）

### ページの流れ

問題の型を選ぶ → 数値をランダムに変えた問題が出る → 答えを入力して答え合わせ → 正誤と解き方を表示し、グラフに正解（実線）と入力した答え（破線）を重ねて描く → 次の問題。
正解数はページを開いている間だけ数え、保存も送信もしない。

### 出題する型

前期期末の過去問（`24試験2前期(数2)2m.tex` 問1）と後期期末の過去問（`24試験4後期(数2)2m過去問.tex`）の 1 行問題から型を取る。

| ページ | 型 |
|---|---|
| 練習: 点と直線 | 2点間の距離、内分点・中点、傾きと1点を通る直線、2点を通る直線、平行・垂直な直線、直線に関して対称な点 |
| 練習: 円 | 円の中心と半径、円上の点における接線 |
| 練習: 2次曲線 | 楕円・双曲線の2焦点 |
| 練習: ベクトル | 単位ベクトル、垂直・平行になる x、線形結合 |

### 数値の範囲

過去問の水準（座標や係数は ±7 程度、分数の答えあり、√ の中は 2 桁まで）を基準に 2 段階にする。

- 試験: 過去問と同じ水準（分数・√ を含む）
- 基本: 答えが整数になる問題だけ

範囲の条件は 1 か所の設定にまとめ、数値を変えるだけで難しさを調整できるようにする。

### 生成

きれいな答えを先に決め、問題の数値を逆算する。問題として成り立たない組み合わせは引き直す。

| 型 | 先に決めるもの | 問題の作り方 |
|---|---|---|
| 2点を通る直線 | 傾き m、切片 n | x₁ ≠ x₂ を選び、yᵢ = m xᵢ + n |
| 円の中心と半径 | 中心 (a, b)、半径 r | 標準形を展開して x²+y²−2ax−2by+(a²+b²−r²)=0 |
| 楕円の焦点 | 分母 A ≠ B | x²/A + y²/B = 1。c = √\|A−B\| |
| 直線に関して対称な点 | P と Q | ℓ を PQ の垂直二等分線にする。係数は (2u, 2v, −(u(p₁+q₁)+v(p₂+q₂)))（u, v は Q−P の成分）を最大公約数で割る |
| 線形結合 | a、b（平行でない）と係数 m、n | c = m a + n b |

答えが分数になる問題は、問題を先に決めて答えを分数のまま計算する。

### 判定

- 入力欄は型ごとに「y = □x + □」「(□, □)」のように □ に数を入れる形にし、整数・分数・√ の組み合わせ（例: `3/2`、`2√5`、`-√3/2`）だけを読む。√ はスマートフォンで打ちにくいので、入力欄の横に √ ボタンを置く。
- 値が等しければ正解にする（√40 と 2√10、6/4 と 3/2 はどちらも正解）。簡単にできるときは「√40 は 2√10 と簡単にできます」と一言添える。
- 直線の入力欄は「y = □x + □」「□x + □y + □ = 0」「x = □」から選べるようにし、係数が比例していれば正解にする。最初に表示する形は、型ごとに過去問の解答例の書き方に合わせる（傾きと1点・2点を通る直線は y = mx + n、平行・垂直な直線は一般形、円の接線は x₁x + y₁y = r² の形）。

### 解き方

プリントの解答例の行を型にし、数値だけを入れ替える。

| 型 | 出どころ |
|---|---|
| 傾きと1点を通る直線 | 2502c の (例1): y − y₁ = m(x − x₁) に代入して整理 |
| 2点を通る直線 | 2502c の (例2): 傾きを求めてから公式 (I)。公式 (II) は別解 |
| 2点間の距離 | 2501c の問1: √((x₂−x₁)² + (y₂−y₁)²) に代入し、√ を簡単にする |
| 直線に関して対称な点 | 2503c の例題3: 解1（PQ ⊥ ℓ と中点の条件で連立）。解2（垂線と ℓ の交点が中点）は別解 |

### 検証

シードを固定して問題を大量に作り、答えが問題の条件を満たすかを CI で確かめる（2 点が直線の上にあるか、PQ の中点が ℓ の上にあり PQ ⊥ ℓ か、m a + n b = c か、など）。

### 実装

[tools/ketjs-build.mjs](../tools/ketjs-build.mjs) はボタンに対応していないため、ボタンと入力欄は普通の HTML にし、グラフだけ CindyJS で描く。
HTML の部品と CindyJS の間で値を受け渡す仕組みをビルドツールに足す。

## 試作で分かったこと（2026-10-15）

cdy 6 本のスクリプトを `ketjs-build` → `ketjs-run` に通した結果。

| cdy | 結果 |
|---|---|
| `2510c/su2(2s)22510c動かす` | そのまま動く。スライダーで直線 y=x+C が動く |
| `2511c/d` | 斜線の領域は描ける。表示範囲がずれ、印刷用の枠線も見える |
| `2514c/提示用cdy/問11(3)(提示用）` | スライダーで動く。表示範囲の調整が必要 |
| `2509c/su2(2m)2408c放物線` | `Putoncurve` の点が用意されず、P を動かせない |
| `2513c/線型結合の説明` | `Putoncurve` の点が用意されず、ほぼ白紙 |
| `2508c/su2(2s)2212wグラフ(画面)` | 例外（`Cannot read properties of undefined (reading 'real')`）で白紙。原因は未特定 |

- `Putoncurve` / `Putonseg` で作る点は、今のビルドツールでは宣言されない。
- `\wx{}` などの TeX マクロは KaTeX で読めず、文字列のまま表示される。
- `Figpdf` など Cinderella 専用の関数は HTML 版にない。
